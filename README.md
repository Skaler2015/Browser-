# TezBrowser 🛡⚡

एक फ़ास्ट, ऐड-फ़्री डेस्कटॉप वेब ब्राउज़र (Windows / macOS / Linux) — Electron (Chromium इंजन) पर बना हुआ।

A fast, ad-free desktop web browser built on Electron (Chromium engine) with a built-in ad & tracker blocker.

## खासियतें (Features)

- 🚫 **बिल्ट-इन ऐड-ब्लॉकर** — Ghostery adblocker इंजन + EasyList/EasyPrivacy फ़िल्टर। ऐड और ट्रैकर नेटवर्क लेवल पर ही ब्लॉक हो जाते हैं।
- ⚡ **तेज़ ब्राउज़िंग** — ऐड/ट्रैकर की सैकड़ों रिक्वेस्ट ब्लॉक होने से पेज काफ़ी तेज़ लोड होते हैं और डेटा भी बचता है।
- 🗂 **मल्टी-टैब** — टैब खोलें/बंद करें (Ctrl+T / Ctrl+W), मिडिल-क्लिक से टैब बंद करें।
- 🔍 **स्मार्ट एड्रेस बार** — URL लिखें या सीधे सर्च करें (DuckDuckGo — प्राइवेसी-फ़्रेंडली सर्च)।
- 🛡 **ब्लॉक काउंटर** — हर टैब पर दिखता है कि कितने ऐड/ट्रैकर ब्लॉक हुए।
- 🚫 **पॉपअप ब्लॉक** — पॉपअप विंडो नई टैब में खुलती हैं, अलग विंडो में नहीं।
- 📌 **ऑटो-लॉगआउट रोकें (Keep-Alive)** — एड्रेस बार के बगल वाला 📌 बटन दबाएँ, तो वह टैब हर मिनट हल्की एक्टिविटी भेजकर साइट को लॉग-इन बनाए रखता है। लॉगिन कुकीज़ भी सेव रहती हैं, इसलिए ब्राउज़र बंद करके दोबारा खोलने पर भी लॉग-इन बना रहता है। (नोट: अगर कोई साइट सर्वर की तरफ़ से ज़बरदस्ती सेशन खत्म करती है, तो उसे कोई भी ब्राउज़र नहीं रोक सकता।)
- 📴 **ऑफ़लाइन कैश** — फ़िल्टर लिस्ट एक बार डाउनलोड होकर कैश हो जाती है।

## इंस्टॉल करने का तरीका (Install — no extra software needed)

कुछ भी एक्स्ट्रा इंस्टॉल करने की ज़रूरत नहीं — बस रेडीमेड इंस्टॉलर डाउनलोड करें:

1. इस रिपॉज़िटरी के **Actions** टैब में जाएँ: `https://github.com/Skaler2015/Browser-/actions`
2. सबसे ऊपर वाला (latest) **Build installers** रन खोलें
3. नीचे **Artifacts** सेक्शन से अपने सिस्टम के हिसाब से डाउनलोड करें:
   - **TezBrowser-Windows** → इसमें `TezBrowser-1.0.0-win.exe` (इंस्टॉलर — डबल-क्लिक करें, अपने-आप इंस्टॉल होकर डेस्कटॉप शॉर्टकट बन जाएगा) और एक portable `.exe` (बिना इंस्टॉल किए सीधे चलाएँ) है
   - **TezBrowser-Linux** → `TezBrowser-1.0.0-linux.AppImage` (executable बनाकर सीधे चलाएँ)
4. ज़िप खोलें और इंस्टॉलर चला दें — बस हो गया! ✅

हर नई push पर इंस्टॉलर अपने-आप ताज़ा बन जाता है।

## डेवलपर की तरह चलाना (Optional: run from source)

अगर सोर्स से चलाना हो तो [Node.js](https://nodejs.org) (v18+) इंस्टॉल करके:

```bash
npm install
npm start
```

अपने कंप्यूटर पर ही इंस्टॉलर बनाने के लिए: `npm run dist`

## कीबोर्ड शॉर्टकट (Keyboard shortcuts)

| शॉर्टकट | काम |
|---|---|
| `Ctrl+T` | नया टैब |
| `Ctrl+W` | टैब बंद करें |
| `Ctrl+R` | पेज रीलोड |
| `Ctrl+L` | एड्रेस बार पर जाएँ |

## स्ट्रक्चर (Structure)

```
src/
  main.js        # मुख्य प्रोसेस: विंडो, टैब, ऐड-ब्लॉकर, नेविगेशन
  preload.js     # UI ↔ main प्रोसेस के बीच सुरक्षित ब्रिज
  ui/
    index.html   # ब्राउज़र का टूलबार UI (टैब बार + एड्रेस बार)
    renderer.js  # टूलबार का लॉजिक
    start.html   # नया-टैब स्टार्ट पेज
```
