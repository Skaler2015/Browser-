# TezBrowser 🛡⚡

एक फ़ास्ट, ऐड-फ़्री डेस्कटॉप वेब ब्राउज़र (Windows / macOS / Linux) — Electron (Chromium इंजन) पर बना हुआ।

A fast, ad-free desktop web browser built on Electron (Chromium engine) with a built-in ad & tracker blocker.

## खासियतें (Features)

**ऐड-ब्लॉकिंग और स्पीड**
- 🚫 **बिल्ट-इन ऐड-ब्लॉकर** — Ghostery adblocker इंजन + EasyList/EasyPrivacy फ़िल्टर। ऐड और ट्रैकर नेटवर्क लेवल पर ही ब्लॉक हो जाते हैं।
- ⚡ **तेज़ ब्राउज़िंग** — ऐड/ट्रैकर की सैकड़ों रिक्वेस्ट ब्लॉक होने से पेज काफ़ी तेज़ लोड होते हैं और डेटा भी बचता है।
- 🛡 **ब्लॉक काउंटर + प्रति-साइट कंट्रोल** — टूलबार पर दिखता है कितने ऐड ब्लॉक हुए; 🛡 बटन दबाकर किसी एक साइट पर ऐड-ब्लॉकर बंद/चालू करें (सेटिंग याद रहती है)।
- 🖼 **डेटा सेवर** — धीमे नेट के लिए इमेज बंद करके पेज और तेज़ खोलें (Settings मेन्यू)।
- 🚫 **पॉपअप ब्लॉक** — पॉपअप विंडो नई टैब में खुलती हैं, अलग विंडो में नहीं।

**रोज़मर्रा की सुविधाएँ**
- 🗂 **मल्टी-टैब** — Ctrl+T नया टैब, Ctrl+W बंद, मिडिल-क्लिक से बंद, Ctrl+Shift+T से बंद टैब वापस; टैब पर साइट का लोगो (favicon) दिखता है, टैब खींचकर आगे-पीछे कर सकते हैं, Ctrl+Tab से टैब बदलें।
- 📍 **पिन टैब** — टैब पर राइट-क्लिक → पिन करें; पिन टैब छोटा होकर बाईं तरफ़ रहता है, गलती से बंद नहीं होता। राइट-क्लिक मेन्यू में डुप्लिकेट/बाकी सब बंद करें भी है।
- 💡 **एड्रेस बार सुझाव** — टाइप करते ही हिस्ट्री/बुकमार्क से मिलते-जुलते पते दिखते हैं (तीर कुंजियों से चुनें)।
- 🏠 **स्पीड डायल** — नए टैब पर आपकी सबसे ज़्यादा खुलने वाली 8 साइटों की टाइलें।
- 📖 **रीडर मोड** — 📖 बटन दबाएँ, आर्टिकल साफ़-सुथरे पढ़ने लायक़ रूप में खुलता है।
- 😴 **मेमोरी सेवर** — 30 मिनट से बेकार पड़े बैकग्राउंड टैब अपने-आप "सो" जाते हैं (💤), RAM बचती है; क्लिक करते ही जाग जाते हैं। पिन/📌/आवाज़ वाले टैब कभी नहीं सोते।
- 🔄 **सेशन रिस्टोर** — ब्राउज़र दोबारा खोलने पर सारे टैब वहीं से शुरू होते हैं जहाँ छोड़े थे।
- ⭐ **बुकमार्क** — ☆ बटन या Ctrl+D से सेव करें; `tez://bookmarks` (Ctrl+B) पर लिस्ट।
- 🕘 **हिस्ट्री** — सर्च के साथ, `tez://history` (Ctrl+H); मिटाने का विकल्प भी।
- ⬇ **डाउनलोड मैनेजर** — प्रोग्रेस, रोकें/जारी रखें/रद्द, "फ़ोल्डर में दिखाएँ" — `tez://downloads` (Ctrl+J)।
- 🔍 **पेज में खोजें** — Ctrl+F, नतीजों की गिनती के साथ।
- 🔎 **ज़ूम** — Ctrl+= / Ctrl+- / Ctrl+0।
- 🖨 **प्रिंट, PDF सेव, पूरे पेज का स्क्रीनशॉट** — File मेन्यू से।
- 🔊 **टैब म्यूट** — आवाज़ वाले टैब पर स्पीकर आइकन, क्लिक करके चुप कराएँ।
- 🖱 **राइट-क्लिक मेन्यू** — लिंक नई टैब में, इमेज सेव, टेक्स्ट सर्च वग़ैरह; माउस के back/forward बटन भी चलते हैं।

**और सुविधाएँ**
- 📥 **बुकमार्क इम्पोर्ट/एक्सपोर्ट** — Chrome/Edge/Brave से एक क्लिक में बुकमार्क ले आएँ (Library मेन्यू); HTML में एक्सपोर्ट भी।
- 🗂 **टैब ग्रुप (रंग)** — टैब पर राइट-क्लिक → रंग चुनें; एक जैसे काम के टैब एक रंग में।
- ⿲ **स्प्लिट व्यू** — किसी टैब पर राइट-क्लिक → "स्प्लिट में दाईं तरफ़ दिखाएँ" — दो साइटें आधी-आधी स्क्रीन पर।
- 🎦 **पिक्चर-इन-पिक्चर** — टूलबार का 🎦 बटन; वीडियो छोटी तैरती विंडो में चलता रहता है।
- 🗣 **पेज पढ़कर सुनाना** — View मेन्यू से; चुना हुआ टेक्स्ट या पूरा आर्टिकल आवाज़ में।
- 🌍 **हिंदी अनुवाद** — View मेन्यू से किसी भी पेज का अनुवाद नई टैब में।
- 🔠 **प्रति-साइट ज़ूम याद** — जिस साइट पर ज़ूम बदला, अगली बार अपने-आप वैसा ही।
- 🎨 **थीम** — डार्क/लाइट/नीला/हरा/बैंगनी (Settings मेन्यू)।
- 👥 **प्रोफ़ाइल** — File मेन्यू से "मुख्य", "प्रोफ़ाइल 2"… — हर प्रोफ़ाइल के अपने लॉगिन, हिस्ट्री, बुकमार्क।
- 📊 **ऐड-ब्लॉक डैशबोर्ड** — `tez://stats`: आज/हफ़्ते/कुल ब्लॉक, 30 दिन का ग्राफ़, डेटा बचत का अनुमान, अपनी कस्टम फ़िल्टर लिस्ट।

**प्राइवेसी और सुरक्षा**
- ⚠️ **ख़तरनाक साइट सुरक्षा** — मैलवेयर/धोखाधड़ी वाली साइटों की सूची (URLhaus, रोज़ अपडेट) से मिलाकर खुलने से पहले चेतावनी।
- 🔒 **HTTPS-only** — असुरक्षित (http) साइट अपने-आप सुरक्षित (https) पर खुलती है; न खुले तो पहले चेतावनी पूछती है।
- 🔎 **सर्च इंजन चुनें** — Settings मेन्यू से DuckDuckGo / Google / Bing / Brave।
- 📂 **डाउनलोड कंट्रोल** — फ़ोल्डर बदलें या "हर बार पूछें" चालू करें।
- 🕶 **प्राइवेट टैब** — Ctrl+Shift+N; न हिस्ट्री बनती है, न कुकीज़ बचती हैं (बंद करते ही सब साफ़)।
- 🧹 **एक क्लिक सफ़ाई** — Settings मेन्यू से कुकीज़/कैश/हिस्ट्री साफ़ करें।
- 🌙 **डार्क मोड (हर साइट पर)** — Settings मेन्यू से; रीस्टार्ट पर लागू।
- 🔍 **स्मार्ट एड्रेस बार** — URL लिखें या सीधे सर्च करें (DuckDuckGo — प्राइवेसी-फ़्रेंडली सर्च)।
- 📌 **ऑटो-लॉगआउट रोकें (Keep-Alive)** — 📌 बटन दबाएँ, तो वह टैब हर मिनट हल्की एक्टिविटी भेजकर साइट को लॉग-इन बनाए रखता है। लॉगिन कुकीज़ भी सेव रहती हैं। (नोट: सर्वर की तरफ़ से ज़बरदस्ती सेशन खत्म हो तो कोई ब्राउज़र नहीं रोक सकता।)
- 📴 **ऑफ़लाइन कैश** — फ़िल्टर लिस्ट एक बार डाउनलोड होकर कैश हो जाती है।

## इंस्टॉल करने का तरीका (Install — no extra software needed)

कुछ भी एक्स्ट्रा इंस्टॉल करने की ज़रूरत नहीं — बस रेडीमेड इंस्टॉलर डाउनलोड करें:

1. इस रिपॉज़िटरी के **Actions** टैब में जाएँ: `https://github.com/Skaler2015/Browser-/actions`
2. सबसे ऊपर वाला (latest) **Build installers** रन खोलें
3. नीचे **Artifacts** सेक्शन से अपने सिस्टम के हिसाब से डाउनलोड करें:
   - **TezBrowser-Windows** → इसमें `TezBrowser-1.0.0-win.exe` (इंस्टॉलर — डबल-क्लिक करें, अपने-आप इंस्टॉल होकर डेस्कटॉप शॉर्टकट बन जाएगा) और एक portable `.exe` (बिना इंस्टॉल किए सीधे चलाएँ) है
   - **TezBrowser-Linux** → `TezBrowser-1.0.0-linux.AppImage` (executable बनाकर सीधे चलाएँ)
4. ज़िप खोलें और इंस्टॉलर चला दें — बस हो गया! ✅

हर नई push पर इंस्टॉलर अपने-आप ताज़ा बन जाता है।

## डेवलपर की तरह चलाना (Optional: run from source)

अगर सोर्स से चलाना हो तो [Node.js](https://nodejs.org) (v18+) इंस्टॉल करके:

```bash
npm install
npm start
```

अपने कंप्यूटर पर ही इंस्टॉलर बनाने के लिए: `npm run dist`

| शॉर्टकट | काम |
|---|---|
| `Ctrl+T` | नया टैब |
| `Ctrl+Shift+N` | नया प्राइवेट टैब 🕶 |
| `Ctrl+W` | टैब बंद करें |
| `Ctrl+Shift+T` | बंद टैब वापस खोलें |
| `Ctrl+R` | पेज रीलोड |
| `Ctrl+L` | एड्रेस बार पर जाएँ |
| `Ctrl+F` | पेज में खोजें |
| `Ctrl+D` | बुकमार्क जोड़ें/हटाएँ |
| `Ctrl+B` | बुकमार्क लिस्ट |
| `Ctrl+H` | हिस्ट्री |
| `Ctrl+J` | डाउनलोड |

## स्ट्रक्चर (Structure)

```
src/
  main.js              # मुख्य प्रोसेस: विंडो, टैब, ऐड-ब्लॉकर, डाउनलोड, हिस्ट्री, मेन्यू
  store.js             # सेटिंग्स/बुकमार्क/हिस्ट्री/सेशन की JSON फ़ाइल स्टोरेज
  preload.js           # टूलबार UI ↔ main प्रोसेस के बीच सुरक्षित ब्रिज
  internal-preload.js  # इंटरनल पेजों (tez://) के लिए ब्रिज (main में sender-वेरिफ़ाइड)
  ui/
    index.html         # टूलबार UI (टैब बार + एड्रेस बार + खोज बार)
    renderer.js        # टूलबार का लॉजिक
    start.html         # नया-टैब स्टार्ट पेज
    pages/
      bookmarks.html   # tez://bookmarks
      history.html     # tez://history
      downloads.html   # tez://downloads
```
